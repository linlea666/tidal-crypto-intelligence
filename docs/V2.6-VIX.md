# V2.6 VIX 美股买入观察

## 原因、边界和复用

原有资产入口、信号评分、研究和邮件审核都围绕 BTC/ETH，直接加入 VIX 会混淆指数单位、交易时段与策略验证。新增独立 `#vix` 页面及类型，不改变资产枚举、BTC 规则、候选审核或研究统计。

直接复用 SMTP 配置、TLS 发送、登录认证、前端请求缓存、ECharts 和视觉变量；扩展 Warehouse 的 `research.sqlite` 独立表及通知类型；提取共用发送账本、滚动小时限额和发送结果落库。源解析、纽约发布时段、周期状态机和页面独立实现。VIX 首屏三个查询串行使用现有缓存，避免突破已有两个并发查询的资源保护。

影响文件为 `internal/datahub/vix_*.go`、Hub 启动/查询/维护及通知模块，`internal/tidal/api_v2.go`，前端 VIX、导航、图表标线、请求入口和健康页。在线备份继续包含原研究数据库；无需新增 secret 或数据卷。

## 数据契约

- [新浪分时](https://gi.finance.sina.com.cn/hq/min?symbol=VIX)：顶层和 result.status.code 均为 0；首行六字段、后续四字段。仅使用时间、指数值和首条日期，不解释未核实字段。
- [新浪说明](https://finance.sina.com.cn/stock/globalindex/quotes/VIX)标注北京时间及至少 15 分钟延迟。用 Asia/Shanghai 解析时间，只允许一次 23 点到 0 点的跨日；交易日按 America/New_York 核对。夏令时由时区数据库处理。
- 发布时段为纽约工作日 03:15–09:25、09:30–16:15。节假日/提前收市日历未作为完整契约接入，正常工作日停更显示过期及待核实，不推测有效行情。
- 每 60 秒抓取一次，非发布时段 15 分钟，覆盖延时收盘并在开盘恢复；连接 12 秒、响应 2 MiB、最多 1500 点，有界退避并尊重 Retry-After。HTTP 200 但源时间停更也会暂停提醒。
- 来源时间超过 25 分钟、获取超过 2 分钟、报错或时间异常都不可触发；仍显示最后有效值和时间。周末旧值显示非发布时段。
- [Cboe 日线](https://cdn-api.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv)每 6 小时抓取，保留近一年。全文件检查结构、日期顺序及容量，仅对导入窗口检查 OHLC。官方早年记录存在部分 OHLC 不一致，未使用的早期价格不阻断当前窗口，近一年异常仍拒绝。
- 日线展示官方收盘及美东日期，不参与盘中提醒。分时缺分钟断线；日线缺失工作日保留空值（可能是休市或未覆盖），不补零。新浪末值不等于 Cboe 收盘。
- `TIDAL_OFFLINE=true` 不启动 VIX 上游或邮件任务；全部浏览器 GET 只读本地。

## 阈值与恢复

| 数值 | 状态 | 邮件 |
| --- | --- | --- |
| <20 | 低波动 | 无 |
| 20–<30 | 波动升高 | 无 |
| 30–40（含边界） | 买入观察 | 本轮一次 |
| >40 | 重点买入观察 | 本轮一次 |

首次取得有效达标数据即入队。普通档升到重点档可追加，直接跳到 >40 只发重点并覆盖普通档；尚未发送的普通档被重点档替代。连续观察到低于 30 满 30 分钟才清空周期，按来源时间计；错误、过期、相邻有效点超过 5 分钟或已知中间高值打断恢复，休市不自动清空。

默认邮件关闭。首次开启可在当前有效值达标时记录“首次启用已达标”；此后关闭期间的事件、同一分钟修正、历史补齐和重启积压不补发。周期状态、事件和通知在一个数据库事务内保存；同档去重状态随重启保留。分钟保存 30 天，事件和 VIX 通知 90 天，周期状态持续保留。

BTC 与 VIX 共用每滚动小时最多 6 次 SMTP 发送。新发送使用独立批次 ID，兼容旧通知的秒级尝试记录；先持久化 sending 和批次，再调用 SMTP。网络或发送结果不确定时不自动重发。发送完成即使原 context 超时，也使用独立短期限保存结果。页面区分等待限额、发送中、服务器接受、结果不确定、停用、过期、重启抑制及来源修正。

邮件包含指数、条件、来源/发现时间、延时说明、美股观察范围及页面链接。SMTP 接受不代表已进入收件箱。本规则不证明底部或收益，不实现 VIX<20 卖出，也不执行交易。

## 认证 API

| 方法和路径 | 内容 |
| --- | --- |
| GET `/api/v2/vix` | 最新值、来源/获取时间、状态、下个阈值距离及设置 |
| GET `/api/v2/vix/history?range=day\|1m\|3m\|1y` | 分时或官方日线，分别标记来源 |
| GET `/api/v2/vix/alerts?limit=20&before=<RFC3339Nano>` | 90 天事件及通知状态，最多 100 条/页 |
| GET/PUT `/api/v2/vix/settings` | 独立邮件开关；PUT 仅接受 `{"emailEnabled":true/false}` |

使用现有会话、同源写保护、查询预算和私有缓存语义。VIX 健康独立于加密行情 `/readyz`，故障不阻断 BTC/ETH 就绪。

## 验收与启用

自动化覆盖数据形状/跨日/DST/重复乱序/错误码/超时/停更，30/40/40.01、跨档、恢复缺口、关闭重开、重启、回填修正、事务失败回滚、共用限额、发送不确定、备份重开和保留期；认证、请求边界和原 BTC/ETH 接口保持回归。

真实契约检查可运行 `TIDAL_VIX_LIVE_CHECK=1 go test ./internal/datahub -run TestVIXLiveContractOptional -v`，仅访问公开行情、不发邮件。浏览器使用独立离线数据库和真实快照检查桌面、1280px、390px、切换范围、邮件开关、源异常与原页面导航。

发布后先核对生产数据，再在开市时验证源时间推进和 25/2 分钟门槛，并完成明确标注的测试邮件后开启自动邮件。真实触发、收件和持续运行分别验收，最新完成情况见 [STATUS](STATUS.md)。
