# BTC 链上筹码：实现与验收契约

后续规则与修复见 [链上筹码v2](ONCHAIN-COST-2.md)。下文保留首版口径、实现和验收历史。

规则 `onchain-cost-1`。独立页面 `#onchain-cost`，导航位于巨鲸之后，仅 BTC，保留其他页面的 BTC/ETH 选择。面向日线、1–8 周观察；不存在订单执行、个人仓位建议、必涨必跌或主力意图推断。

## 根因与修改边界

盘口是订单库存，主动成交是交易流，链上成本是最后移动供给；三者不能共用单位、分类或阈值。价格附近的移动窗口会随价格改变，分类也会因币龄改变。因此新模块独立解码与计算，同时展示固定美元区间变化，分开陈列跨来源证据。

长期成本历史不能放进现有最长90天的事实清理链路。新 `onchain.sqlite` 纳入 Warehouse 打开/关闭、总磁盘统计和在线备份，独立失败只降级本页。未修改原现货、资金预警、清算、VIX规则及研究清理策略。

直接复用会话认证、8秒API查询预算、HTTP ETag、共享查询缓存/去重、前端串行GET、Chart/ECharts、事实首次可见读取、精确金额工具与SMTP批次/限流。通知选择器扩展为排除 `onchain-cost:%`，该类型由独立任务拥有；跨库交接使用唯一事件ID。成本分桶、日线规则、修订和长期结果独立实现，避免交易语义耦合。

## 证据完整性

现货聚合配置包含Binance/OKX/Coinbase/Kraken/Bitfinex，可计算完整5分钟格的日时间覆盖；其契约没有逐家有效覆盖字段，**即使时间覆盖>=95%，仍标记共同来源覆盖未知/证据不足**，不能假装已实现五家完整证据。没有新增CoinGlass请求补猜。

数量OI与美元名义价值OI按同一UTC日两个边界分别读取；美元变化不解释为BTC增仓。资金费率保留来源、实际类型、计费周期，未知不平均。实际清算金额不使用模型强度。ETF按报告日、明确最终状态及对账结果展示，非交易日不填零。原事实不可得或超时，显示缺失及原因，不使用部分读取伪装完整。

## 研究与通知

历史探索列出真实快照集中度、收盘波动与后续7/14/30/60日结果，标记事后可得，不计入前向统计。前向仅对实际发现的价格确认/集中事件研究，从发现后的首个完整UTC日开始，以发现日收盘为基准；记录收盘收益、收盘路径最高/最低和后续波动。截止日次日06:00 UTC定稿，只用此时之前首次取得的价格修订；后到数据不覆盖缺失结果。

每规则/方向/期限分别统计完整、等待、缺失和重叠。按事件时间贪心保留非重叠完整区间；至少30个才展示收盘上涨占比及Wilson95%区间，明确不是交易胜率或策略有效性证明。初始化无自然样本属于正常状态，不能预写长期结论。

邮件开关默认关，只控制新事件；打开不补发现有状态，关闭终止待发意图。事件与outbox同库同事务写入，幂等交接共享notice；共享每小时最多6次批量发送、SMTP结果未知不自动重试。重启用冻结事件的纳秒发现时间判断积压，避免秒级共享表误抑制刚启动后产生的新事件。发送结果复制回长期outbox，避免共享表90天清理后丢失投递状态。

- `warehouse.go/hub.go/views.go`：可降级生命周期、独立任务与健康入口。

- `internal/tidal/api_v2.go`：经过既有认证的设置写入，仅一个布尔值。
- `web/src/OnchainCost.tsx`、`onchainCost.css`：独立页面、表格证据与响应式图表；App/Pages/data仅增加接入与串行读取归类。
- `deploy/compose.yaml`、`deploy.sh`、`cmd/tidal/main.go`：功能关闭变量、新库备份、回退终止待发意图。

GET `/api/v2/onchain-cost`、`/history`、`/events`、`/research` 全部只读本地；GET/PUT `/settings`控制独立邮件。首屏组合请求；历史、事件、研究按需。历史/事件/研究有界分页，2MiB响应目标/硬检查，不突破全局8MiB。日期只有真实快照；表格可键盘点击回放；热力图真实时间留空。

独立库128MiB含WAL/SHM；80%提示，95%暂停。事务提交前保留缓存/索引/WAL增长余量，预计触线则整体回滚，可能早于实际95%拒绝新增；不删审计证据。仍允许关闭邮件。数据库不可用不影响现有市场模块。
