# 看板使用说明

打开交付的 HTTPS 地址，输入独立看板密码。访问地址和密码保存在本机已忽略的 `secrets/access.json`，不要上传这个文件。关闭页面不会停止服务器采集。

## 读懂横向价位柱

1. 选择 BTC 或 ETH。上方红色柱表示卖单，下方绿色柱表示买单，中央标出当前价格。
2. 柱长表示该价格区间的有效美元挂单金额，买卖两侧共用同一线性刻度。默认只展示重点价位，点击“展开全部”可查看筛选范围内其他价位。
3. “价格精度”决定合并多少美元为一档；“范围”决定离现价多远；“持续”筛掉存在时间较短的区域。
4. 点击一根柱子，右侧查看金额大小、持续时间、成交证据和交易所贡献。这三类证据分别展示，不是胜率或价格必然反弹的承诺。
5. 底部查看所选区域的金额变化，单独选择回看范围。进阶热力图可用按钮切换，不影响默认柱状读法。

挂单可以随时改变。断线、覆盖边界或汇率变化导致的减少不会标成确定撤单；区间长期有挂单也不表示始终是同一笔订单。未覆盖、过期和未采集的历史会标记或留空，不用零值补造。

## 其他页面

- 总览：综合现货报价 OHLC、买卖墙、成交与合约摘要。报价 K 线是多平台有效报价的观察区间高低开收，不冒充某家交易所的成交 K 线。
- 成交分析：分现货/合约查看主动买卖、VWAP、CVD、价格成交分布和足迹。主动净买入是买入额减卖出额，与充值提现不是一回事；CVD 从当前选择窗口起累计。
- 合约态势：三家 BTC/ETH USDT 永续的单边 OI、资金费率与实际周期、基差，以及平台公开发布且系统观察到的清算。清算列表不是全市场完整统计。
- 巨鲸：Hyperliquid 已监控地址的前10/50名、方向筛选、持仓均价和动态清算分布。清算价可能为空；设置杠杆、全仓和逐仓含义不同。有效实时汇总只计最近90秒更新的核心持仓。
- 数据健康：查看来源覆盖、汇率、异常与资源预算；设置30或90天保留；管理手工价格标注。

“标注开仓 / 止盈 / 止损”只保存个人计划和盈亏比，不连接交易权限，也不提交订单。可在数据健康页删除标注。

## 历史、更新与维护

服务器从首次采集时刻开始形成盘口和巨鲸历史；刚上线时没有过去30/90天的数据。选择90天表示以后保留较长的降采样历史，不会生成不存在的历史。

默认分层保留：5秒盘口约24小时（按日分区清理最多多留1天）；1分钟统计30天；巨鲸地址5分钟快照30天；15分钟汇总最长90天。项目预算20GB，至少保留8GB空闲，空间不足会暂停细历史写入并标记缺口，实时显示继续。

更新始终按本地 → GitHub 检查 → 正式 Release → 镜像 → 服务器执行。普通提交、草稿或预发布不会更新生产，发布失败会尝试恢复已成功部署的上一版本。详见 [运维说明](OPERATIONS.md) 和 [验收状态](STATUS.md)。
