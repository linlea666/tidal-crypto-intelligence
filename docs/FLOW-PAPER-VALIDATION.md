# 资金研究可靠性与永续合约模拟

本次依据批准方案分成两个可独立回退的 Release。正式 flow-multifactor-v1 阈值、邮件、事件和前向起点不变。已有失败、未知和研究覆盖不追认。实施状态及验收证据记录在 STATUS.md。

## 可靠性根因与复用

原历史检查点依赖 count/max(available)；滚动清理删除旧事实就使已完成的计算失效。research-3.0 在采集结束或24小时采集期限后冻结输入，所有事实和影子样本通过相同上下文读取不可变快照。旧任务保留结果和检查点，追加旧状态归档并停止重复计算；新版本链接原研究。原有线上的事实读取只增加显式错误返回，不因 SQL 异常生成0/0版本。

复用 gzip 事实、FactsAsOf 口径、检查点、订单触发器计数、SQLite在线备份及现有UI。新增 study_inputs 清单和 study_input_chunks 分块，保留来源修订及首次可用时点；逐块摘要和分块数量校验，分页最多256行/256KiB事实载荷，解码块不超过1MiB。构建只保护相关时间范围、固定采集截止前的事实，24小时后终止释放保护。单份64MiB/总128MiB计入原512MiB研究预算，不增加连接或总资源限制。容量不足产生明确不完整结果，不驱逐正在计算的输入。

维护原来在hub事务内重新扫描全部金额载荷。order_storage已经覆盖订单、流动性和区域样本，改用计数器，禁止重复加区域计数。short-flow publication只在新输入出现时写入；读失败不是不存在。短状态与检查点写入在现有单连接上按剩余阶段预算限制SQLite busy handler，并恢复连接原等待策略。最近失败时间、操作、类别与错误不随成功清除；页面暂停状态读取失败维持未知。

接口兼容增加 inputSnapshotId/inputFrozenAt/inputIntegrity/terminalReason/parentStudyId，POST studies 可传 parentStudyId 创建新版本。冻结统计不因补采重写。所有资金影响计算仍由后续模拟账本承担，历史关联收益不标为交易胜率。

## 模拟首版固定实验

Binance BTCUSDT USDT本位永续，公共数据。正式首次异动触发，两组各10,000 USDT，单笔1,000 USDT名义金额，最多一笔。实际接收事件后至少1秒，使用随后收到的新鲜对手报价，额外不利滑点2bp、单边费用5bp；不是账户实际手续费。新报价超5秒、信号超30秒、ATR/合约/资金不满足均跳过，保留原因。

反向信号退出组无策略止损或持仓时限。风控组采用14个完整小时的ATR，冻结1ATR止损、2ATR止盈、4小时退出。两组相同准入与成交模型；同向不加仓，反向先平后开，触发退出原因不变，报价数量只能使用一次。公开实际资金费按[入场,出场)计入，不把待结算当零。

独立paper.sqlite含WAL上限128MiB，16MiB预留给收尾；原总磁盘预算不变。信号发布事件与正式提交同事务，账本消费/仓位/成交/费用原子提交并去重。行情断流/重启停止开仓，恢复报价退出已有仓位并标记数据中断；30秒连续正常后仅接收新事件。历史回放与前向账本分开，永不补造历史成交。不连接交易账户。

新增大资金动向“模拟仓位”：运行质量、两组账户、业绩、交易依据、跳过与异常。金额十进制字符串、未知null。完整净收益与已知部分分开，异常交易仍进入账户总账，完整样本另列。30天/每组100笔完整平仓/各方向30笔/95%覆盖只是阶段审查门槛，不构成可实盘结论。

## 实现边界与接口

`paper_collector.go` 独立处理公共合约 REST 和两个 WebSocket；`paper_engine.go` 负责单写者状态机；`paper_store.go`、`paper_funding.go`、`paper_recovery.go` 保存及对账实验状态、不可变成交与账务；`paper_views.go` 提供本地只读统计。旧信号事务只追加首次发布 outbox，模拟账本按实验代次、组别及信号ID去重，消费位置和成交一起提交。正式规则、邮件逻辑、ETH均不接入模拟策略。

复用现有 decimal、SQLite在线备份、认证、缓存和图表组件。完整K线校验、完整小时ATR和分位数纯函数原样提取到 `hourly_atr.go`、`research_statistics.go`；原研究口径不变。模拟合约、持仓和资金费独立编写，避免现货成交或信号确认流程承担持仓职责。

新增认证 GET `/api/v2/paper`、`/api/v2/paper/trades?group=risk&limit=25&offset=0`、`/api/v2/paper/trade?id=…`。参数与金额保留十进制字符串，未知保留null；GET不采集上游。列表按开仓时间倒序，单笔包含首次发布快照、可行动时间、ATR完成边界、每次成交的一档报价/数量/时间、费用与资金费取得时间。当前概要5秒缓存，独立只读连接和读取事务避免页面阻塞模拟写入或拼接不同账务状态。

报价和标记价路径使用接收时间及事件时间双重有效性检查；quote update ID 只能使用一次（两组是独立实验，各自拥有同一条报价的可见量）。bookTicker是完整买卖一档快照，不将跳号当作L2增量缺失。队列最多256条、延迟超过1秒即标为路径缺口，WS最多两条并指数退避。REST单请求5秒、至少2秒间隔、最多4MiB返回，429/418退避；公共路径白名单禁止非行情端点，完全不使用账户密钥或CoinGlass配额。原始报价仅驻留有界队列，不建立无期限逐笔行情表；成交依据与账本长期保留。

资金费每次请求最多24小时，重叠复查最近一小时，已知逾期而未返回的结算时间持续重试。水位推进不能把待结算变成零。结算按真实持仓区间逐笔入账，SQL毫秒索引只筛候选，最终按完整时间精度核对部分成交。官方修订与不可变账本冲突时保留原记录，写失败诊断并使受影响净收益未知，不静默改写历史资金费。

## 统计解释

账户总账包含异常退出；净胜率分母是已平仓且资金费完整的交易；另列路径完整子集，阶段门槛只计算路径与账务都完整的样本。共同入场比较要求同一事件在两组都已平仓并结算完整，避免一组先退出造成选择偏差。首次发布等级冻结，事后突破不改变入场类别。

净值包含未实现盈亏，60秒采样但保存实际采样时钟。分钟内发生又恢复的缺口也会留下空点；相邻记录超过65秒视为断点。回撤计算全期保留序列的连续可见区间，图表展示最近24小时，不能声称逐笔或缺失区间极值。市场暴露按实际开平仓区间累计，MFE/MAE是持仓期间收到的可平仓一侧报价相对入场价的每BTC波动，异常路径必须结合质量标记阅读。

费用敏感性在相同成交路径上追加一倍手续费和不利滑点成本，资金费不变，不重新优化退出。按日重采样使用UTC入场日、含零交易日的日收益/日笔数块、固定随机种子和2,000次采样；达门槛后给出95%净期望区间，不直接给出实盘许可。完整资金费未知时，不展示完整净收益。

## 启用、容量及恢复

服务配置 `TIDAL_PAPER_MODE=off|collect|run`：程序默认off，生产Compose首次发布默认collect；collect只验证公共采集，不能开启实验。验证实际生产报价、标记价、完整ATR、合约过滤器和资金费后才切换run。run在连续30秒有效行情、ATR与合约有效、空间可用时原子开启两组，保存同一启用时钟及当时outbox终点，跳过此前所有历史事件。参数JSON与规则版本写入实验，二进制参数不匹配时拒绝解释旧账本；后续参数实验需要新的版本和起点，不能清库重置成绩。

独立paper库计入原项目磁盘统计；库/WAL/SHM合计上限128MiB，112MiB后禁止新开仓并预留16MiB收尾，接近硬限制先有界checkpoint再保守拒绝写入。数据库页上限120MiB预留WAL空间，保留成交、资金费、研究输入及净值证据；空间不足不删历史业绩。备份清单从完成的副本读取实验代次和消费位置，标明必须与同批research恢复。启动逐笔对账成交/费用/资金费、仓位余额及账户投影；不一致停用模拟模块并明确报告，其他页面仍可运行。

进程重启、来源数据库恢复、行情或处理路径缺口均暂停新入场并标注现有仓位。已有退出原因不覆盖，质量标记仍记录数据中断；合约暂停或未知期间保留待平仓，不能制造不可执行成交。恢复后用实际新报价、至少1秒延迟退出，连续30秒正常后只接受新事件。回退保留paper库；切collect可停止新入场并继续收尾，切off则暂停本模块，恢复run必须经过恢复检查。

## 验收与回退

覆盖滚动删除与新增修订不重置、失败/超时不伪装成空输入、租期和容量、备份恢复、订单计数全表对账；完整race/vet与前端检查。受限Linux原1.7核/768MiB、600MiB目标及5小时15分钟长回放必须据实验收。浏览器1440与390检查输入/缺口/错误/ETH。模拟再加金融、部分成交、资金费边界、重复事件、重启及不足样本回归。
