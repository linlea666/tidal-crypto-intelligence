# BTC现货挂单变化与成交承接

本模块执行已批准的“BTC主链路优先”方案。规则 `spot-book-flow-v1`、采集配置 `btc-spot-priority-v1`，只做站内前向观察，不创建邮件，不改变正式异动、分层影子候选或A/B模拟的入场条件。挂单量来自CoinGlass原始价量快照，成交来自同交易所现货足迹，不能推断资金身份、逐笔撤单或可执行成交。

## 根因、范围及复用

旧足迹以五分钟粒度每十五分钟取得，实时窗口可能已经过时；盘口与大额挂单占用的请求量使仅延后清算地图无法满足核心提速。旧页面还有固定“每两/五/十五分钟”文案，直接改注册频率会造成误导。改动覆盖注册表、统一调度、分钟足迹契约/五分钟聚合、时效元数据、独立研究存储和大资金动向页面，原严格TTL不随降频放宽。

直接复用decimal、有效FX、认证、Quota、原生历史、在线研究库备份和图表；扩展调度优先级/诊断/契约/查询；提取固定价区与分钟聚合纯函数；独立实现观察状态机、不可变登记与前向结果。共享既有研究连接，10秒后台周期、2秒阶段预算，不进入永续报价消费循环。子预算32MiB，单行工作集1MiB，最多128个未解除区域；达到预算明确停止登记，保留证据。原研究512MiB、paper128MiB及20GB总限制不变。

名义9.773611次/分钟，包含暂停中的历史任务登记预算。两家分钟契约验证期间旧五分钟足迹仍运行，名义约9.906944次/分钟。统一滚动12次/分钟、5.1秒间隔、最多两个在途不变。核心四任务固定相位6/19/32/45秒，失败遵守原退避；恢复后回到自身固定频率，不追赶每一个错过的请求。正式依赖仍高于低频背景，历史仅使用实时任务剩余额度。

一分钟足迹使用独立 `.minute-v1` 来源。通过真实Normalize路径检查闭合时间、价区、非负数量和原生币数量×价区范围与报价金额一致性。至少三次独立推进、每次包含五个连续完整分钟才验证通过；十次未验证则停探测、保留旧来源。验证后设未来完整五分钟边界，仅当新边界后五个分钟全部具备才写入旧页面兼容聚合并停旧任务。历史身份不覆盖、不重复累加。缺失/空窗口保留未知。原生细历史沿用七天保留。

已验证一分钟来源可通过既有认证补采队列申请近72小时内、单次最多一小时的补缺；不绕过额度，不将补采计入及时覆盖，不改变新事件首次资格。自动重叠请求只覆盖最近十分钟，更长缺口仍明确显示，不能因历史补齐抹除前向失败。

## 固定观察与证据

同交易所/同现货交易对/同原生报价100单位网格，两格组成200单位区域；扫描有效盘口参考价附近1%。30分钟前向预热，29/30可比分钟数量中位数为基准；2倍且数量增量按当前区域VWAP和有效FX折算至少100万美元即发布。数量变化不受汇率涨跌或价格靠近原有买墙制造假增长。返回范围未完整包围区域、数量缺失或基准为零时未知。

另一次独立请求、源时间至少相隔一分钟且仍增强，追加“后续快照仍在”。五个完整一分钟足迹滚动计算：确定落入区域的金额≥100万美元，相反主动方向占比的保守下界≥60%，前后可比同侧深度保持≥70%，追加被动承接/抛压线索。前盘口不晚于窗口开始、后盘口不早于窗口结束，各在90秒内；永久保存所用区域原始价量、修订与FX。无法取得同一修订原始证明时承接未知。主动同向占比≥60%独立追加主动跟进。跨边界足迹不猜分，边界全部金额计入不利分母。

窗口至少包含首次发布之后新完成的一分钟，追加状态各自保存真实可读时间，收益不倒推。源/取得超过三分钟不发新观察，迟到和修订不能回填首次资格。连续两次独立参考价越过不利边界为失守；深度跌至首次50%为消退；断流/重启终止连续证据路径。最长30分钟，区域重叠去重并固定最早区域；连续十分钟有效观察不满足资格才解除，缺口重置连续时钟。有效参考价离开该固定区域搜索范围只代表不再符合观察范围，不当作挂单归零。

## 时间、统计与接口

研究起点首次run原子保存。事实提交后读取成功才保存发布时钟与结果登记，API隐藏尚无发布时钟的行。首次事实、每种状态及发布时间不可覆盖；事件投影与冷却状态可更新。登记失败不会把下一次重试回填成当时可见。后续成功不清除最近错误。

认证只读 `GET /api/v2/book-flow`，支持 `asset=BTC`、`direction=buy|sell`、`from/to`（最多七天）、`id`、`limit`（最多50）、`offset`。`alert-audit?layer=book`可关联查询。详情包含同期正式异动、通知接受及模拟成交，时间关联不代表因果。GET只读本地，不触发上游。

采集诊断记录计划频率、实际成功间隔、源延迟、排队和请求耗时。及时覆盖按实验开始后完整源分钟计数：两家盘口与足迹分别首次在三分钟内取得，期限结束冻结分母与四项覆盖位；重复请求不多算，事后补齐不追认。预热与进程停机仍计入覆盖分母。

增强/承接/跟进分别从实际发布后的下一根完整五分钟现货开盘，观察5/15/30/60/240分钟收益、MFE/MAE及时点。观察价格不是永续模拟成交价，不含成本。统计分列全部、重叠、价格可计算与输入证据完整样本。每方向每阶段取最早事件，其后四小时内跨交易所/区域观察单列重叠，避免夸大样本。复用原行情片段一对一匹配提前/跟随/漏报；相对正式信号提前量只在同一行情片段配对，不用不相关事件凑提前性。

至少30天、100个独立成熟且证据完整观察、两方向各30、及时覆盖95%才进入阶段审查。按UTC日块含无样本日、2000次固定种子重采样。报告达到3000观察读取上限明确截断并禁止阶段判断。该研究不替代原模拟完整平仓门槛。

## 发布、回退与验收

`TIDAL_BOOK_FLOW_MODE=off|collect|run`：程序默认off，稳定Compose默认collect。collect应用新采集配置/验证分钟契约，但不建立研究起点；验证后配置run启动前向预热。off恢复原注册配置并停止新生成，原事件、证据和账本保留。采集配置版本随新正式首次信号冻结，影子/模拟原始快照沿用，原起点不重置。

每次发布从本地到GitHub及稳定Release；配置切换/部署中断旧72小时区间，保留旧失败，新run容器建立独立固定身份，不拼接。受限长回放、同版本72小时运行、研究效果分别判断。工程测试与真实分钟契约、95%及时覆盖不同，详见STATUS实际结果。

测试覆盖原始解析→入库→独立worker→原始前后深度证明、买卖对称、负Delta承接、边界保守、旧来源切换、重复/迟到/重启/容量原子回滚、只读认证及全任务额度压力。资源回放同时运行正式研究/模拟/雷达/新观察和本地GET，在1.7核/768MiB下输出独立book-flow.json；合成夹具仅测试环境，永不注入生产。
