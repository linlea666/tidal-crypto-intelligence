# V2.9：5／10分钟独立资金观察

## 根因与范围

原正式资金判断取完整成交和价格K线共同截止时间。成交先到、K线后到时，15分钟卡片与正式条件一起等待；标题只说明当前条件，未同时解释最近正式事件。因此“行情已上涨、当前持续性不足、此前已有正式事件”可能同时成立，却难以从首屏区分。

本版为BTC增加独立成交观察与前向研究；ETH、正式 `flow-multifactor-v1` 门槛、去重、解除/重触发与邮件状态机不变。短周期没有通知入口。资金是主动买卖成交差额，不是充值提现或新增资本。

采集审计另发现明确的闭合边界缺陷：上游返回的形成中1分钟记录可先被标为有效，随后仅凭本地时间过去而进入完整窗口。本版在成交标准化时排除尚未结束的记录；新研究也拒绝不能证明在闭合后获取的旧事实版本。原事件与邮件账本不改写。这是影响本功能正确性的输入修复，不调整正式策略阈值。

## 复用与影响范围

| 部分 | 决策及理由 |
|---|---|
| CoinGlass采集、额度、FX、美元金额格式化 | 直接复用，无新接口、无新增常驻上游请求、不提高频率 |
| 完整5分钟聚合、窗口求和、方向分位、价格突破匹配 | 扩展复用，5/10分钟建立自己的分布，原调用语义保留 |
| 最近正式事件、阻断明细、窗口卡片 | 扩展组合接口，提取前端公共展示；最近事件不受历史规则筛选影响 |
| 原始首次可见事实、价格事件、有效清算区域 | 直接复用，只读引用并在提示发生时冻结 |
| 短周期观察、研究检查点、容量控制 | 独立模块/表/版本，不耦合正式提醒与邮件 |

代码集中在 `shortflow*.go`、资金组合接口、研究组合接口、`FlowObservation.tsx`、`ShortFlowStudy.tsx` 与对应资金页面/测试。未改动交易执行、现货墙、巨鲸算法或清算状态机。

## 固定计算口径

- 统一最新完整成交截止，提供5/10/15/60/240分钟及六段独立5分钟。缺分钟则对应完整窗口金额为空，零成交与买卖平衡独立处理。
- 30天基线排除当前未完小时及紧邻一小时，沿用原研究保守隔离口径；每5分钟平移计算各自窗口，买卖正向净额分别P95。至少95%时间覆盖、21个各含≥274个完整5分钟的UTC日期。
- 5分钟提示：方向净额≥同方向本周期P95，量比≥1.5，主导方≥55%。10分钟增加两根独立5分钟同向条件。1小时反向只展示冲突，不否决短周期提示。
- 只有完整且截止距当前≤5分钟的窗口可产生新提示；读取时还检查观察快照是否90秒内更新。原金额可作为带时间标签的历史参考；基线不足时只显示金额。
- Binance BTC/USDT同窗价格从首根开盘至末根收盘，全部K线齐备才展示。此前14个完整小时ATR独立计算；价格、ATR缺失不阻塞成交。
- 清算关联仅选择当时完整、35分钟内、同USDT报价、未触及且仍位于现价相应一侧的最近区域。保存版本、获取/可见时间、参考价和距离；模型强度仍非美元，不与成交相加。
- 合约背景保留自身正式快照和数据截止。不存在未来数据补齐后改写提示证据的过程。

## API与持久化

`GET /api/v2/signals?asset=BTC` 兼容增加 `observation` 和 `latestFormal`；原 `current` 是正式评估快照。两者时点不同时分别标注，阻断项的实际值来自 `current`。

`GET /api/v2/studies?asset=BTC` 兼容增加 `shortTerm`。所有GET仅读本地，不能采集上游或建立观察事件。ETH不启用。

`flow-observation-v1` 在研究库新增 `sf_records`/`sf_budget`；包含固定origin、30天基线/检查点、首见覆盖、同向行情事件及原正式/价格对照。升级为增量建表，SQLite在线备份自然包含新表；镜像回退仍可使用原表。不得删除库来回退。

- 原512MiB研究总预算内32MiB子预算，SQLite触发器原子累计payload及行开销。旧等量检查点可更新；满额/重启不重置origin。
- 明细最长30天；仅保留完整基线工作检查点及当前聚合状态。读取单行≤1MiB、事件≤32KiB、基线≤8640条、报告≤2000个紧凑试验、待推进每批≤4个事件。
- 后台独立轮转观察/基线/结果任务，每阶段2秒context，10秒轮转，成交观察通常30秒一次。冷基线最多48小时一片、保存进度；逐小时复用未修改历史，仅补增量。没有提高768MiB容器或12次/分钟上游额度。
- 最大基线检查点反序列化、分布运算及再序列化无GC分配边界测试低于8MiB；共享SQLite/流式SQL与其他模块并发的总资源另用Linux回放验收。
- 容量、超时、写入错误保存缺口并暂停新研究事件，行情展示继续。连续三个阶段成功才解除暂停；暂停期间的首见覆盖保留为无效，不能事后补造成功窗口。

## 前向研究

上线origin单独持久化，重启不改变；上线前已知案例、历史重建价格事件不进入新验证。每个5分钟截止只登记首次实际可见快照，后续修订只更新当前页面，不补记新提示。

同方向4小时内归为同一观察事件，分别记录5/10分钟首次提示。冻结成交、基线、价位/ATR、当时已跟随价格的状态和可用清算区域。事件从发现后的下一根完整5分钟K线开盘开始，统计15/30/60/240分钟方向位移、MFE和MAE。K线最迟20分钟可见，过期缺口固定为不完整；处理后的数值不因历史补采或修订改变。

价格事件复用原一对一时序匹配；每侧比较5分钟、10分钟、原正式规则、价格突破。候选两侧前后4小时共同覆盖≥95%，不足单列排除；价格事件成熟8小时再比较，使±4小时内资金提示的共同窗口有机会完整。未匹配提示最长等待12小时，不能将尚未成熟视为漏检，亦不能将未匹配视为亏损。

每方向≥14天、有效覆盖≥95%、≥30个独立可比价格事件才显示提前捕获比例及Wilson 95%区间；此前仅数量、覆盖与进度。比例不是交易胜率或未来概率，位移不含交易成本。不同规则分组不相加，短周期参数不自动调整正式规则。
