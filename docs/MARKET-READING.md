# 市场解读看板

大资金动向默认打开“市场解读”，按当前判断、关键价区、事件进展、背景与分歧、历史验证阅读。保留原当前动向、异动预警、挂单与承接、历史复盘、模拟仓位和钱包入口。

## 判断范围

解释规则 `market-reading-v1` 复用已认证只读的activity/book-flow/settings接口。不新增采集、研究登记、交易执行或邮件规则。观察窗口默认1小时，可切4/24小时，进入当前动向和返回时保持；成交结论仍采用原后端规则和原覆盖/边界条件。

响应超过45秒、原来源到期、请求失败、窗口不完整时不采用当前成交方向。挂单还检查原180秒盘口源/取得时间、研究处理时钟、运行模式、事件有效期与证据路径。每5秒本地重新判断到期，不新增网络请求。某项不足只限制该项；ETH不会借用BTC挂单或结果。

同一成交窗口包含反向挂单发布时可描述为证据分歧。不同时间范围只并列描述，不合成概率或综合分数。承接必须已有发布阶段及原始前后证明；主动跟进独立展示。减少、失守、断流、过期或不完整路径不再作为当前有效线索。所有历史阶段时间保留。

## 阅读与跳转

1. 当前判断：显示观察范围、成交与同窗价格解释、挂单现状、下一步需要什么证据。结论可下钻同一成交窗口。
2. 关键价区：卖单在上、买单在下，中间分别显示Binance/OKX参考价。每侧至多两处，已满足增强且基准完整的区域优先，再按距本所价格的距离排序。同来源重叠区域不重复选入；展开全部仍使用同一美元线性刻度，绝不合计重叠金额。FX未知时保留未知，不画美元金额条。可比较历史不足用文字解释。
3. 事件进展：显示最新已加载事件，明确48小时范围与非全市场。首次增加、持续确认、承接/抛压是独立已登记阶段，不是自动完成的任务进度；终止状态单独显示。点击进入具体事件ID与同期关联，键盘焦点落到事件段落。
4. 背景：同窗合约变化、正式规则及钱包分开；OI不解释为单方面开多/开空，链上/ETF等慢频信息不混进分钟判断。
5. 结果：四个阶段各自使用完整证据独立样本数量及其均值。无成熟完整样本时不显示零收益卡。达到门槛只代表可审查；原前向起点、覆盖分母、历史失败、手续费和模拟账本不变。

提醒入口只展示原设置并导航至邮件面板，导航不会发送测试或变更开关。诊断与原始按交易所价区仍可展开。桌面与手机使用原石墨、薄荷买方、珊瑚卖方主题，状态同时有文字说明。

## 验收边界

本次为前端信息架构与解释层变更，没有新增后端写入路径。前端回归覆盖独立有效证据、源/请求过期、未知与零、不同时间窗口、区域重叠、阶段原始证明、事件终止及预热状态。浏览器采用明确标记的本地离线夹具，禁止所有写请求；上线另验真实数据与版本。独立资源回放结论按其源码树记录，不借旧版本产物宣称新树通过。
