# V2.1 挂单口径与大资金动向

本版修复的是呈现口径。此前BTC662档、ETH530档独立复算没有发现五家漏加；五家接入不等于每个价位的五家深度均完整。本档金额仍为价格×基础币数量×USD汇率，再按交易所相加，保留原有数值算法。

## 页面与口径

现货挂单页增加所选价格范围的已覆盖买卖总额、最早/最晚来源时间；金额为当前存量，每档宽度单独显示。来源为CoinGlass最新1分钟切片，约2分钟采集；不是小时或日累计成交，也不是完整实时L2。重点列表/持续筛选不改变范围总额。侧栏分别展示有返回金额、仅处于返回范围、本档未覆盖及过期情况。

“大资金动向”页面只做BTC/ETH现货大单与合约背景，默认1小时/现价±5%；可看4小时、24小时。当前大单价格范围不裁剪全市场成交统计，事件列表覆盖全部价位。概况、价格反馈、CVD共享截止最近可比闭合5分钟的时间窗。主动买占比≥55%为买方较主动，≤45%为卖方较主动；至少90%有效分钟、首尾边界和新鲜行情/成交才给方向，否则证据不足。价格±0.05%内为小幅波动；与成交方向一致/背离只描述观察，不识别主力身份或预测胜率。规则版本`evidence-2.1`。

CVD与主动净买卖只有一份基础事实，不重复计分。足迹保持原始USDT，与全市场USD净买卖分开；三家足迹与五家盘口共同来源仅Binance、OKX。主动方向不能从挂单方向推断：买挂单成交是被动承接。OI变化采用实际采样端点，仅有邻近窗口边界时展示；不同结算周期资金费率保留原值，不相加。逐笔大额成交尚未接入，不画成交圆圈。

## 共享数据契约

- `GET /api/v2/activity?asset=BTC&hours=1&range=5`：本地组合查询。返回实际from/to、覆盖比例/边界、元数据、价格/CVD、足迹独立口径、合约背景、有效大单、最近100条采样事件、历史补采进度及持久化容量缺口。
- `GET /api/v2/levels`：保留旧字段，新增`summary`（bidCents/askCents/zoneCount/hasData/oldestSourceAt/newestSourceAt）及`coverageKind`。缺少有效美元价格时，相对价格范围不能计算；不将全景金额冒充±10%。
- `GET /api/v2/large-orders?asset=BTC&history=1&limit=100&offset=0`：最多300条/页；hasMore表示下一页。历史金额保留reportedUsd，不计当前挂单。新增initialQuantity/initialUsd/executedQuantity/rawState/endAt；空字段保持空。
- 所有GET只读本地；认证先于缓存。新页面复用现有抓取、标准化、财务算法、窗口统计与前端数据客户端，不增加按页面的上游请求。

## 大单生命周期

规范身份是来源＋市场＋交易所＋交易对＋上游ID。实时和历史共用`tracked_orders`，事实变更保存在`order_events`。创建、变更、结束、获取时间分开。历史查询明确传`start_time/end_time`，按结束时间推进；state2为上游结束，state3为上游标记撤销。不把结束记录中的剩余量视为正在挂单，也不将记录结束等同全部成交。

首次发现仅建立基线，不把累计历史成交放进当前窗口。连续两次观察才产生区间变化；数量增加与成交数量分开。原币成交数量不随FX变化；上游USD累计变动只作附属事实，不用余量差推撤单或强行计算完成率。累计回退/同一来源时间修正时撤回旧增量、重新建立基线；旧响应不覆盖新事实。仅时间更新不会产生新的金额变化事件。从列表消失不产生平仓/撤单推断。

每个市场结束/撤销各有一个持久任务。满100条先拆时间窗口，页未完整前不推进；空数组有效，业务失败/null/无效状态或时间越界不推进。分割、失败和重启后的待补窗口仍经过唯一额度入口。无法继续细分、越过可保留范围或容量暂停时保留缺口说明。实测代理state=3筛选曾返回rawState=2：保留记录原始“已结束”事实，不强行标撤销，同时持久标记该筛选历史不完整，并继续后续窗口，避免无限重试消耗额度。首次从上线前30分钟开始补采，历史覆盖起点公开；未回填的30天不能宣称完整。

## 刷新与资源

盘口120秒；大单300秒/有效720秒；Hyperliquid300秒/逐条源时间480秒，榜单、分布、监控共用常量。钱包是按需缓存，8分钟有效。历史两种状态各1800秒，其他原频率不变。正常平均约10.63次/分钟，滚动60秒硬限12次且至少错开5.1秒。到期当前数据始终先于历史；HTTP失败与重试同样计数，429全局退避，401/403暂停。

生命周期表是hub.sqlite的增量兼容扩展，不删除/修改旧表，可回退V2.0。细事件/结束记录保留30天；删除前按完整小时生成事件数量摘要，到90天。摘要不是累计成交金额。大单子预算512MiB，按记录、键和索引开销估算，每次写入计数；项目物理占用/WAL/备份仍受20GB及最小8GB空闲保护。容量暂停保留本地当前快照，永久标记对应小时缺口。SQLite在线备份包括新增表。
